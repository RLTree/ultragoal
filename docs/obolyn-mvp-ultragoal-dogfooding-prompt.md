### Goal

Build the smallest clean-room Obolyn design-partner alpha candidate that makes
the closed Resume → Review → Correct loop real for one de-identified bulk
RNA-sequencing project.

A researcher must be able to return after a 21-day absence, reconstruct

sample-identity correction through every known dependency, and receive a new
Resume Brief that excludes superseded state.

### Success means

- Project Home answers Now, Why, Changed, Blocked, and Next using cited current
  project objects.
- Review Queue routes decision-bearing work rather than acting as a
  notification inbox.
- Review Packet binds the exact artifact version, dataset and sample
  identities, method, environment, run receipt, claims, evidence, limitations,
  contradictions, reviewer eligibility, and allowed decisions.
- Review produces a durable typed decision with rationale, inspected evidence,
  limitations, and an actual downstream state effect.
- The reference packet exposes a sample-label swap, wrong reference genome,
  missing quality-control exclusion, unjustified threshold, and non-robust
  conclusion.
- Correct preserves the old record, creates the corrected version, computes
  the affected, unaffected, uncertain, and blocked Impact Set, prevents stale
  reuse, invalidates affected acceptance, and reopens required reviews.
- Project state is derived from append-only typed events; projections can be
  rebuilt without losing decision history.
- Artifact Versions, Claim-Evidence Links, Science Run Receipts, Review
  Decisions, Correction Events, and graph edges have stable identities and
  version binding.
- One bounded in-app Research Mission Contract previews an agent analysis,
  receives explicit approval, executes through typed tools, emits a receipt,
  and returns its untrusted output for independent scientific Review.
- Restart, stale-version, denied-authority, interrupted-run,
  correction-recovery, incomplete-lineage, no-memory, and agent-self-approval
  paths fail visibly and safely.
- H1-REQ-001 through H1-REQ-011 in the planning inventory map to current
  behavior and exact-candidate evidence without treating any complete
  later-horizon workflow or component as required.
