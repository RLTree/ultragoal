| ej observe/compare/detail/links | UG facts/evidence views | Retain original inputs and exact detail; no second evidence owner |
| ej check | UG adopted legibility/ownership obligations | Explicit requirement mapping and unsupported states; no automatic universal cap |

Do not infer consumers solely because a command exists. A temporary alias must identify its new owner, preserve old response compatibility where promised, and expire after consumer migration and two qualified releases (proposed policy). Unsupported compatibility returns a clear migration action, never a fabricated successful old envelope.

Project requirement migration is conservative: inventory adopted rules and their origins, map each to a new obligation/assurance, compare before/after applicable coverage, and obtain explicit adoption for any removed/weakened rule. A universal default judged unhelpful is not permission to erase a user’s deliberately adopted requirement.

Cache migration can discard/rebuild derived values; authority cannot. Never translate an old whole-candidate receipt into current proof solely by matching names. Import only verifiable source/tool/input facts, with legacy provenance and assurance limits. Keep old raw files untouched until all supported readers and rollback no longer need them.

## Rollback behavior

Rollback is a version/reader switch, not a recursive directory overwrite. Stop new semantic requests, mark active operations superseded, preserve useful immutable computations, and reject late admission. Restore exact prior package/configuration through the native host. Reconcile a target’s changed files against saved preimages; if user edits intervened, prepare a three-way restoration patch for authorization instead of overwriting them.

A rollback may restore old functionality with old coverage limitations. It cannot claim new guarantees or translate incomplete work into successful evidence. Keep verified observations and findings for diagnosis, minimize retained sensitive packets, and follow the adopted deletion policy. Provider cancellation may not reverse billing.
