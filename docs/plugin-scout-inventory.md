# Plugin Scout Inventory

Observed at: 2026-06-16T00:00:00Z

This bounded inventory is a proposal artifact, not runtime proof. It records which available plugin families should inform the Harness Ultragoal plugin and what they must not own.

## Recommended

- Superpowers: planning and disciplined workflow method references. It informs skill ergonomics; it does not own proof or completion.
- Compound Engineering: compound review, worktree, proof, and design-review patterns. It informs reviewer/agent design; it does not replace project-local contracts.
- Codex Security: trust-boundary and proof-integrity review patterns for a plugin that manages local execution.
- Browser, Computer Use, Chrome, Playwright: UI proof surfaces when a claim is UI-surface-specific. CLI proof cannot substitute for these.
- OpenAI Developers: current OpenAI platform/API semantics if the plugin implementation integrates with platform APIs.
- GitHub/Linear: optional external task/PR surfaces; parsed into typed records only when the repo uses them.

## Skipped By Default

- Domain-specific plugins such as payments, calendar, mail, analytics, or design tools are not core to ultragoal correctness.
- Connectors are helpers. Core correctness lives in files, schemas, validators, receipts, and repo-local artifacts.
