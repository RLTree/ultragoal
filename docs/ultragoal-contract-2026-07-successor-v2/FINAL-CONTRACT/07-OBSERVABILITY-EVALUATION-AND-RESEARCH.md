# Observability, Evaluation, Improvement, and Research

## Observability

Stable semantic events bind context/candidate identity, causal parentage, operation, outcome, duration, selected/reused/skipped work, finding/repair references, and bounded sensitivity-tagged attributes. A zero-dependency local query plane must explain timelines and root causes offline. Read queries write nothing. Optional exports are adapters and event rows cannot set claims.

## Evaluation and improvement

Evaluation tasks map to product requirements and exact behavior; datasets and fixtures carry provenance and contamination checks; scorers are perturbation-tested against verbosity, proof artifacts, receipt production, test manipulation, and other reward-hacking paths. Canonical run records are vendor-neutral; OpenAI trace grading, Promptfoo, or successors are optional adapters.

Promotion requires paired baseline/candidate evidence, representative behavior improvement, guarded non-regression, bounded change, rollback, and independent review. A metric gain is only an improvement candidate until real product journeys pass.

## Research classification

Every source separates:

1. verified source fact;
2. binding product requirement adopted by this contract;
3. advisory practice;
4. experimental hypothesis;
5. rejected recommendation.

Current capability, model, host, version, benchmark, or vendor claims must be refreshed from primary sources before dependent implementation or release decisions. External research cannot silently change law; promotion requires reviewed contract, impact, migration, proof, and authority changes.
