# Design Docs Index

Root `DESIGN.md` defines design routing and proof requirements.

Use this directory for durable design records:

- product journeys and view specifications;
- design-system decisions and tokens;
- accessibility and interaction reviews;
- screenshots, traces, or links to generated proof artifacts;
- design debt that should become checks or product backlog.

New design records must name the product surface, user job, proof command, and
acceptance artifact.
