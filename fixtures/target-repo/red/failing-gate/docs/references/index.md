# References Index

References are inputs, not law. Repo-root docs and mechanical gates decide
current behavior.

Use this directory for distilled third-party docs, source snapshots, API notes,
design-system references, deployment references, and domain references that
agents need to work without browsing or relying on memory.

Each reference entry should name:

- source and retrieval date;
- reason it matters;
- freshness risk;
- owning doc or check that applies it.
