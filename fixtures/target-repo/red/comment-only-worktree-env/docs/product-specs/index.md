# Product Specs Index

Root `PRODUCT_SENSE.md` defines how agents turn product asks into users, jobs,
constraints, non-goals, risks, and acceptance criteria.

Use this directory for durable product specs. Each spec should name:

- user and job;
- product surfaces touched;
- non-goals and claim ceiling;
- acceptance command, route, screenshot, trace, receipt, or artifact;
- Product Cohesion evidence when the change is user-facing.
