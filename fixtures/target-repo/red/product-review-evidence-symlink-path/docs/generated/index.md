# Generated Docs Index

Generated docs are read-only outputs from commands. Do not hand-edit generated
files unless the generator contract says the file is an editable seed.

For each generated artifact, record:

- generator command;
- input paths;
- output path;
- freshness rule;
- owner for regeneration failures.

Add repo-specific generated maps such as database schema, API schema, CLI help,
route maps, coverage summaries, or dependency inventories only when the repo has
that surface.
