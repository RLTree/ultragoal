# Product Success Contract

This template is mandatory for product-impacting Harness Ultragoal goals. It records target user or operator, job to be done, context of use, desired outcome, mission outcome, critical journey, first value event, quality-in-use dimensions, accessibility, cognitive load, recovery burden, trust burden, continuance policy, forbidden substitutions, non-goal product claims, and claim ceiling.

Required authority lives in the schema-bound JSON contract and receipt. Markdown is a reader projection only.
